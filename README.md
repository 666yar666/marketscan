# 🛒 MarketScan: Умный поиск по маркетплейсам

MarketScan — это мощное веб-приложение на базе **Streamlit**, предназначенное для одновременного поиска и анализа товаров на крупнейших торговых площадках (OLX, Prom, Rozetka, Hotline, eBay). Приложение автоматически отсеивает "мусорные" объявления, фильтрует аксессуары, конвертирует цены по актуальному курсу НБУ и визуализирует распределение цен на рынке.

## 🌟 Основные возможности

- **Мультиязычный интерфейс (i18n):** Поддержка Русского, Английского и Украинского языков. Переключение "на лету" без перезагрузки.
- **Безопасная авторизация (OAuth 2.0):** Интеграция с Google Login (через механизм PKCE) + локальная база пользователей на базе SQLite с хэшированием `bcrypt`.
- **Одновременный асинхронный парсинг:** Быстрый сбор данных с разных маркетплейсов одновременно с использованием `asyncio` и `curl_cffi` для обхода защит.
- **Интеллектуальная фильтрация:** Отсеивание чехлов, кабелей и нерелевантных товаров благодаря встроенному анализатору на базе алгоритмов нечеткого поиска (`rapidfuzz`).
- **Мониторинг цен:** Динамический парсинг курса НБУ и автоматическая конвертация цен (UAH / USD).
- **Визуализация рынка:** Построение Scatter-графиков распределения цен и расчет медианной стоимости для б/у и новых товаров.

## 🛠 Технологический стек

- **Frontend / UI:** [Streamlit](https://streamlit.io/)
- **Парсинг:** `BeautifulSoup4`, `curl_cffi` (обход Cloudflare / анти-бот систем)
- **Обработка данных:** `Pandas`, `asyncio`, `rapidfuzz`
- **Авторизация:** `google-auth-oauthlib`, `bcrypt`
- **База данных:** `SQLite`

## 🚀 Локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/666yar666/marketscan.git
   cd marketscan
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Подготовьте файл Google OAuth (опционально, для локального входа через Google):
   Поместите ваш `client_secret.json` в корень проекта. Этот файл игнорируется Git'ом (см. `.gitignore`).

4. Запустите приложение:
   ```bash
   streamlit run app.py
   ```

## ☁️ Деплой на Streamlit Cloud / Hugging Face Spaces

Проект полностью готов к развертыванию. Чтобы Google авторизация работала в облаке, вам **не нужно** загружать `client_secret.json`. Вместо этого:
1. Зайдите в панель управления вашего приложения в Streamlit Cloud.
2. Перейдите в **Settings** -> **Secrets**.
3. Скопируйте структуру из файла `.streamlit/secrets.toml.example` и заполните её своими реальными ключами. Приложение автоматически переключится на использование `st.secrets`!
